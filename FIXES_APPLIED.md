# Viraj Jewels — Homepage layout update

## Final homepage structure
1. Small announcement bar
2. Compact luxury header with menu, logo, navigation, wishlist and cart
3. Search bar directly below the header
4. One horizontal circular category strip — image + name only
5. One main luxury hero / animation powered by Admin Homepage media
6. Compact editorial tiles: New Arrivals, Best Sellers, Festival Edit, Bridal Edit, Daily Luxury, Silver Stories
7. Trending Jewellery horizontal product rail
8. Small festival campaign
9. New Collection horizontal product rail
10. Newsletter + footer

## Design rules
- No large “Shop By Category” heading on the homepage.
- Categories are circular and stay in one horizontal row; mobile can scroll horizontally.
- Gold/Silver are communicated subtly through category/navigation rather than large homepage blocks.
- Only one large hero/animation is used.
- Homepage product cards stay visual and compact.
- Editorial tiles are small and image-led.
- Existing cart, wishlist, product detail, Supabase and admin functionality are preserved.
